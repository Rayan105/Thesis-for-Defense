## 1. Decision Question (`UD13`)
Select a **single canonical deep learning framework** resolving `fydp_title_proposal.pdf` (`RF08` mentioning both PyTorch and TensorFlow) for implementing Tiers 1, 3, and 4 neural architectures across `REL0001` (`Stage S10–S15`).

---

## 2. Options Considered
- **Option A (`Selected — PyTorch 2.x + Scikit-Learn + XGBoost/LightGBM`):**
  1. **Native Missing-Modality Attention Masking:** `torch.nn.TransformerEncoder` / `nn.MultiheadAttention(key_padding_mask=...)` natively accepts per-patient boolean **`~ModalityMask_CELS`** masks (`[C, E, L, S]`) without workarounds, enabling clean Zero-Leakage partial-cohort training across `DS0001–DS0004`.
  2. **1D-ECG & Multimodal Research Ecosystem:** Direct alignment with verified top Q1 literature (`P0016` PyTorch DeepSHAP, `P0012` CaMPNet, `P0014` MAF-Net, `P0038` MACE-MAIS) plus native Kaggle T4/P100 GPU AMP, `Captum`/`DeepSHAP`/`GradientSHAP`, and deterministic state-dict + optimizer RNG checkpointing (`CKPT####`).
  3. **Seamless Interoperability with Kaggle Workflow:** Matches our Stage S10 PyTorch DataLoader specification in [CVD_Multimodal_Kaggle_Notebook_Guide_PP0001.pdf](../05_Preprocessing_Alignment/notebooks/CVD_Multimodal_Kaggle_Notebook_Guide_PP0001.pdf).
- **Option B (`TensorFlow / Keras Only`):** Rejected (`Requires custom masking wrappers for heterogeneous missing-modality Transformer blocks and has weaker Captum/DeepSHAP parity for hybrid 1D+2D+Tabular Transformers`).

---

## 3. Framework Disposition
- **Selected Framework:** **PyTorch (`torch >= 2.1`)** for all deep neural / Transformer models (`1D-ResNet/CNN`, `CNN-BiLSTM`, `2D-ECG CNN`, `Simple/Gated Fusion`, `CVD-MM-Transformer`) alongside **`scikit-learn` (`LR, RF, SVM`)** and **`xgboost` (`XGBoost`)** / **`lightgbm`** for tabular comparators (`UD14`). Exact runtime versions will be pinned in `STEP-024` (`environment/model/`).
